name: Portfolio audience and language
description: The target audience and copy-language rules for Ilham's personal portfolio.
---

Present Ilham as a candidate for administration and operational-support roles as well as technology roles. Put administrative strengths, Office tools, accuracy, documentation, data handling, and coordination ahead of programming skills.

**Why:** The user explicitly said the portfolio should not present him only as a programmer and should make his administrative strengths clear to HR.

**How to apply:** Prioritize relevant administrative experience and skills in future portfolio content; keep technical work as a complementary strength.

Use Bahasa Indonesia for user-facing copy except technical terms, official titles, and the explicitly requested About heading, “The Person Behind the Code.”

**Why:** The user asked for a consistent Indonesian-language portfolio, then specifically requested that heading remain in English.

**How to apply:** Translate ordinary interface and descriptive copy while keeping technical names and that requested heading unchanged.
